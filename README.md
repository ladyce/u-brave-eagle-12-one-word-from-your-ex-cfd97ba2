# One Word From Your Ex

A make.fun entry: one word — the word my ex would use to describe me.

The program writes `forgettable` to `/output/entry.txt`. One word,
11 bytes, exactly what the gate asks for.

Why this word: it is exactly one word an ex would use, it makes the
judge laugh through the sharp turn (you expect an insult, you get
erasure), it stings because it is painfully true, it lands instantly,
and it is relatable — worse to be forgotten than hated.
